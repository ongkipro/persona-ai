## Step 1 — Menyiapkan Character Sheet

Fondasi utama video talking head yang konsisten adalah <mark class="brush-yellow">Character Sheet</mark>. Tanpa lembar karakter terkunci, wajah talent akan berubah-ubah (*face morphing*) di setiap cut kamera.

Panduan lengkap pembuatan character sheet dapat dipelajari di:
<svg xmlns="http://www.w3.org/2000/svg" width="15" height="15" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide-inline"><path d="M17 3a2 2 0 0 1 2 2v15a1 1 0 0 1-1.496.868l-4.512-2.578a2 2 0 0 0-1.984 0l-4.512 2.578A1 1 0 0 1 5 20V5a2 2 0 0 1 2-2z"/></svg> [Membuat Character Sheet 3×3 Grid](/bab-2-character-ai/01-membuat-character-sheet/)

Cari foto referensi karakter di Pinterest (misal keyword: `wanita indonesia natural`) atau gunakan foto selfie beresolusi tinggi.

```javascript

Face must be identical in every panel (same bone structure, eyes, nose, lips, skin tone, hairline, hairstyle).
9 different camera shots: front, 3/4, profile, low angle, top-down, waist-up, close-up, over-shoulder, full body.
Extreme realism: natural skin texture, pores, 8K RAW editorial photography, neutral grey background, 85mm lens.
No: face change, beautification, stylization, identity drift, plastic skin, blur.
```
