## Platform Overview: Vios Studio

### Apa Itu Vios Studio?

<mark class="brush-green">Vios Studio</mark> adalah platform agregator AI buatan Indonesia (Bahasa Indonesia & mata uang Rupiah) yang berfungsi sebagai **gudang multi-model AI terlengkap**. Satu akun langganan memberikan akses ke puluhan foundation model visual terkemuka sekaligus:

- **Koleksi Model Terlengkap** — Menggabungkan generator video dan gambar dari provider kelas dunia dalam satu dashboard terpadu.
- **Akses Model Tanpa Kunci Tier** — Seluruh tingkatan paket mendapatkan akses ke semua engine model tanpa diskriminasi paket.
- **Transparansi Biaya Kredit** — Biaya pemotongan kredit per varian model tertera jelas dan dapat dipantau real-time.
- **Kontrol Efisiensi Biaya** — Kreator bebas memilih tingkat rendering (Lite untuk draft volume tinggi, hingga Quality untuk shot utama).
- **Spaces Workflow Builder** — Canvas modular untuk merangkai pipeline kreatif mandiri.

#### Katalog Model Unggulan

| Kategori Visual | Pilihan Engine Model |
| :--- | :--- |
| **Model Video** | Veo 3.1 (Quality / Fast / Lite), PixVerse (v6, v5.6, v5.5, v5, C1), Seedance 2.0 (+Fast), Kling (o3, v3), Grok Imagine, Sora 2 (+Pro), HappyHorse 1.0 |
| **Model Gambar** | Nano Banana (+2, +Pro), Seedream (4.0, 4.5, 5.0 Lite), Kling 3.0, Kling o3 Image, Qwen Image, GPT Image 2.0 |

> [!NOTE]
> **Analogi Produksi:** Jika Qreed AI adalah *meal-kit package* terpandu, Vios Studio adalah **supermarket bahan baku premium** — seluruh varian model tersedia lengkap. Kreator memiliki fleksibilitas tertinggi meracik model terbaik sesuai anggaran produksi.

### Efisiensi Biaya per Tingkat Kualitas Video

Sebagai tolok ukur, berikut perbandingan biaya kredit pada model **Veo 3.1**:

| Tingkat Kualitas | Biaya Eksekusi | Skenario Penggunaan |
| :--- | :--- | :--- |
| **Lite** | **5 kredit** | Eksplorasi ide, draft storyboard, volume massal |
| **Fast** | **40 kredit** | Produksi konten feed harian dengan kualitas stabil |
| **Quality** | **220 kredit** | *Hero shot*, materi iklan komersial utama |

> [!IMPORTANT]
> **Prinsip Manajemen Anggaran:** Kunci efisiensi di Vios Studio adalah mengatur tier rendering. Gunakan <mark class="brush-yellow">Lite</mark> untuk eksperimen angle gerak, lalu render final dengan **Fast** atau **Quality** hanya untuk shot yang lolos seleksi.

### Rekomendasi Berdasarkan Profil Pengguna

#### 1. Kreator Pemula

| Keunggulan | Aspek Perhatian |
| :--- | :--- |
| Akses puluhan model premium mulai dari Rp99.000 | Pilihan model sangat banyak, memerlukan waktu adaptasi |
| Biaya kredit transparan memudahkan estimasi produksi | Antarmuka berbasis pilihan manual tanpa template kaku |
| Seluruh varian model terbuka sejak paket terendah | Kuota gambar di paket Creator masih memotong kredit |

> [!TIP]
> Awali dengan paket **Creator** dan optimalkan model **Veo 3.1 Lite** agar kredit tahan lama selama proses pembelajaran. Tingkatkan ke model Fast hanya saat merilis konten publik.

#### 2. Agensi & Kreator Menengah

| Keunggulan | Aspek Perhatian |
| :--- | :--- |
| **Agency Lite** memberikan gambar Nano Banana/Qwen tak terbatas | Siklus masa aktif kredit bulanan |
| **Agency (Studio)** membuka seluruh model gambar secara unlimited | Ketersediaan model pihak ketiga mengikuti status upstream |
| Fleksibilitas tinggi menggabungkan multi-engine dalam satu alur kerja | — |

### Rangkuman Keputusan

- Vios Studio merupakan pilihan ideal bagi kreator yang menginginkan <mark class="brush-green">koleksi model paling variatif</mark> dengan fleksibilitas pemilihan kualitas rendering.
- Manfaatkan fitur **Unlimited Image** di paket Agency Lite / Studio sebagai pabrik foto karakter AI secara hemat biaya.
- Terapkan strategi bertahap: rancang draft dengan mode Lite, dan finalisasi video penting menggunakan model Quality.
